# 별빛 항로: 폭풍 구조대 v2

중1 순서쌍과 좌표·그래프를 사용하는 12개 임무의 턴제 구조 전략 게임입니다. 기존 별빛 우편국 저장소를 재사용합니다.

## 실행

- Node.js 20 이상: `npm start`
- 검증: `npm test`
- 정적 빌드: `npm run build` → `dist/`
- Vercel에서 이 저장소를 Import합니다. `vercel.json`의 빌드/출력 설정이 적용됩니다.
- 배포 성공 전에는 실제 플레이 URL이나 배포 완료를 기록하지 않습니다.

## 플레이

좌표를 입력해 비행선을 조종합니다. 구조자는 한 명만 태울 수 있고 같은 글자의 대피소에서 내려줍니다. 모두 구조한 뒤 기지로 돌아오세요. 지나가는 칸에서도 탑승·하차·장치·급유가 적용됩니다.

이동 한 칸은 1턴·연료1, 대기는 1턴·연료0입니다. 생각하는 동안 시계는 멈춥니다. 시한은 대피소 도착 기준이며, 마지막 턴에 내려주면 성공합니다. 관제 장치를 방문하면 관문이 열립니다. 파고 통로는 **각 칸에 도착할 턴**의 그래프 값이 기준 이하일 때만 통과됩니다. 급유소는 첫 방문에만 탱크를 채웁니다.

1–2: 좌표와 부호 → 3–4: 한 좌석과 긴급 구조 순서 → 5–6: 관문 선행 조건 → 7–9: 미래 파고, 대기와 우회 → 10: 일회용 급유 → 11–12: 규칙을 결합한 구조 작전.

실패하면 직전 행동을 되돌리거나 다시 시작할 수 있습니다. 3별은 목표 턴 이내 도움 없이 성공, 되돌리기·막힌 출발은 최대2별, 힌트는 최대1별입니다. 마지막 임무와 별은 localStorage에 저장하며 기존 우편국 기록과 분리했습니다. 모든 임무를 선택해 연습할 수 있습니다.

## 제작과 근거

기획 비교·난이도 근거는 `design.json`, 교과서 개념과 쪽수는 `sources.json`, 생성 이미지와 프롬프트는 `assets/prompts.json`에 기록했습니다. 원본 PDF, 추출문, 교과서 그림은 포함하지 않습니다. 배경·비행선·폭풍과 구조자·대피소·급유소·관제 장치는 내장 이미지 생성 에셋입니다. 수학 그래프와 좌표는 코드로 정확히 표시합니다.

검증은 12개 임무의 해 탐색과 독립 불변식 대조, 실패 전략, 연료·시한 경계, 실제 브라우저의 승리·복구·저장·모바일 검사를 포함합니다. 실제 학생 대상 재미나 학습 효과 평가는 아직 수행하지 않았습니다.

## 성취기준 확인

게임의 `성취기준 확인 · 기록`에서 독립 확인 과제, 도움/재시도 구분, 학생 설명과 교사 검토, JSON 내보내기·인쇄를 제공합니다. 기준·범위·출처는 `assessment.json`에 있습니다. 기록은 해당 기기의 브라우저에만 저장되며 게임 점수와 별개입니다. 공식 이수나 성적을 자동 판정하지 않습니다. 학교 평가와 함께 사용할 형성평가 증거입니다.
